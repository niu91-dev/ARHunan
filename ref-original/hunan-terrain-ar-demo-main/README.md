# 湖南地形全息扫描 Web Demo

本 Demo 使用上一层 `dem/` 中的真实高程数据生成三维地形。沙盘水平放置，观察相机位于南侧边缘支架上的 Pad 位置。地形上叠加稀疏扫描点云、由相邻点云样本生成的动态短连线、待机扫光和点击扩散扫描。线条的长度、强度和显隐各有随机差异，在扫光中心增强，扫过后淡出。

## 打开

在本目录运行：

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8767/`。使用本地 HTTP 服务是因为浏览器需要读取二进制高程数据；直接双击 HTML 不行。

## 操作

- 支架：拖动安装高度、离中心距离、镜头缩放和沿边左右位置滑杆。镜头默认 2.0×，即原始横向视角角度的一半；离中心距离最小值仍在沙盘边缘外。
- Pad 视线：拖动画面或按方向键，水平限位 ±18°、垂直限位 ±12°；拖动时画面跟随鼠标同向。中间按钮复位，滚轮调节距离。
- 扫描：点击地形触发以落点为中心的点云波；侧栏按钮触发中心波；开关控制待机随机扫光。
- 地点：11 个锚点按经纬度投到 DEM。点击地形标签或侧栏地点名称查看资料。Pad 中央暖色圆形瞄准点进入图标原始半径后开始聚焦，放大后需离开约两倍半径才退出；聚焦时待机扫光暂停，按地点类型与走向扩大周围点云的亮度范围。照片卡分别位于左上和右下，每 6 秒轮播一次，右下切换时间错开 3 秒；右上介绍和左下关键读数自动翻页。

`build_assets.py` 可从 `../dem/湖南高程_米.npy` 重新制作网页用的颜色纹理和高程网格。`vendor/three/` 是本地 Three.js 模块，可离线运行。来源和数据处理见 `../dem/README.md`。

`sites.js` 保存地点文案与示意锚点，`DESIGN-NOTES.md` 记录设计依据和坐标处理方式。前一版连续网格保存在 `app-v1-grid.js`，仅有点云和极弱网格线的版本保存在 `app-v2-points.js`。

当前点云贴近 DEM 表面，点是实心小亮点；短连线使用有轻微扰动的局部三角邻接，只连接靠近且高差较小的点，沿整段线每约 4 mm 重新采样实际 DEM 三角面，统一抬高 3.5 mm 以避免深度冲突。圆形地点图标来自 `assets/location-icons-atlas.png`；六组 `location-photos-atlas*.png` 是 AI 生成的概念影像，用于交互动效预览，不能作为地点实景照片使用。暖色圆形瞄准环停留约 0.5 秒后，连线先从地点长出，卡片再从线端放大；移开时卡片先收回，连线随后消失。点击图标后，卡片保持展开直到移动 Pad 或重新扫描，侧栏同步展示完整档案。

此版本用于视觉与交互效果验证，高程作了适度垂直夸张，不用于测绘或工程设计。地点解释文案按用户提供的草稿展示，尚未逐句完成科学审校。


## R04 单独确认扫描效果

打开 `http://127.0.0.1:8767/?review=scan`。这里隐藏地点和资料，只显示地形点线、待机扫光与轻柔扩散；可切换仅点/仅线并调节光感。`scan-surface.js` 是独立扫描模块，主 Demo 与此页共用。

- 点线位置固定，亮度缓慢呼吸；扩散波只调制表面点线，不添加悬浮环或扫光墙。
- 准心改为轴对称同心环；进入区域收拢提亮，0.5 秒后锁定。Shift + 方向键可精细调整视线。
- 资料连线为单段三次贝塞尔曲线，卡片根节点就是末端。线先展开，卡片从末端长出，退出反向执行。
- 左上固定使用 atlas / b / c，右下固定使用 d / e / f，每地点 6 幅独立概念影像。每组 3 幅、6 秒一换，右下错开 3 秒。新增图片由内置 imagegen 生成，提示词保存在 `assets/photo-prompts-r04.txt`。
- AR 防抖已做浏览器界面的微动平滑和 160 ms 短时退出容错；正式 AR 仍需稳定世界锚点与位姿滤波，详见 `AR-INTEGRATION.md`。左下角红字提醒必须保留给接入人员。
- 前一版源文件保存在 `revisions/r03-before-polish/`，仅供源码对照。

验证：在真实高程网格上用 Three.js 射线抽样核对了 120 个连线点与表面的间距；浏览器确认了连线先行、卡片展开和反向回收阶段。视觉效果与最终设备跟踪表现仍需人工及现场确认。


## R05 定位与环境反馈

- 保留 R04 点线拓扑，默认光感从 1.15 提高到 1.75，继续使用加法叠加。地点聚焦范围缩小，并按高程带柔化过滤：山岳为局部块、平原为低地块、河流为狭长代表河段。仍是视觉近似，不是精确 GIS 边界。
- 图标悬浮在地面坐标上方，使用细引导线关联贴合 DEM 的地面定位微光。小定位动效受省域遮罩裁切；展开资料时从相同地面坐标发出扫描波。
- 未聚焦准心采用高对比暖色双环与轴对称呼吸；聚焦后收成小亮点，避免盖住资料。
- 待机每约 1.2–3 秒在视野中的地形样本上产生随机微光。视线移动后，在空白地形停稳 0.48 秒，中心射线实际落点产生一次轻柔涟漪；继续静止不会连续重复，移动后重新启用。


## 摄像头实景叠加预览

侧栏顶部提供两个独立按钮：“开启摄像头”和“关闭参考模型”。开启摄像头后，视频铺在透明 WebGL 背景下；隐藏参考模型会同时隐藏地形实体、底座和地面网格，保留扫描点线、定位微光、地点图标和资料交互。再次点击可分别恢复。关闭摄像头或离开页面会停止所有视频轨道。

此功能仅做屏幕视觉合成：没有真实空间定位、环境遮挡或设备姿态跟踪。隐藏的 DEM 仍用于扫描形状和虚拟射线落点。优先请求后置摄像头，不请求麦克风，不录制或上传画面。需要浏览器摄像头授权；当前 localhost 地址可用，手机远程访问应使用 HTTPS。


## R06 准心节奏涟漪与定位光标

R06 取代 R05 的随机待机微光和随机横向扫光。未聚焦地点且准心实际落在参考 DEM 上时，从当前落点发起一圈涟漪；该圈在 6 秒内消退，最早 6.8 秒后才从新落点发起下一圈。没有地形交点时不发波；聚焦地点时暂停待机波。图层隐藏后仍使用同一虚拟 DEM 计算落点，不做真实空间定位。

准心 SVG 明确使用形状自身的边界框中心缩放，避免负坐标 viewBox 引发偏心。地面定位标记加强为亮芯、双环、扩散圈及短光柱；主扫描光感默认 2.4，实景模式隐藏模型时进一步增强亮度和微光。摄像头开启/关闭及参考模型开关保持独立。

### R06.1 选中地点的全图涟漪

选中地点的扫描波改用沙盘米制距离，与局部地貌高亮范围分离。从地点地面坐标向外传播，按该地点至湖南省域最远点线样本的距离自动计算传播半径；接近最远边缘的最后 10% 距离才开始消退，整圈消失后留 0.85 秒间隔。速度为 0.68 m/s，柔和波带宽度 0.40 m；波纹亮度系数由 0.26 提至 0.48，取消原先随局部范围距离快速衰减的系数。点线仍沿原 DEM 表面分布，待机涟漪节奏保持原设置。
