怎么用
1. 把平板横着装到固定支架上，镜头对准沙盘中心 （先对准，再进入 —— 顺序反了模型会锁在错的姿态上）
2. 点「进入 AR 沙盘」，允许相机权限
3. 屏幕中央会出现湖南地形（带地名标签）
4. 缓慢左右旋转 / 俯仰平板 —— 地形固定在真实空间里，转视角就像透过窗口看沙盘
5. 点地形上任意位置选中最近的地点，右侧弹出介绍卡
6. 左侧「设置」可调沙盘宽度 / 相机高度 / 相机距离 / 起伏 / 水平视场角

没对准？点底部「重新对齐」会按当前姿态重新锁一次。

注意：这条路线只有旋转没有平移。 平板一旦移动位置，地形就会跟着滑动 —— 这是 3DoF 的固有限制。 所以它适用于「固定在支架上只转不移」的展项形态。

实物是起伏模型时必做：虚拟地形的垂直比例必须和实物一致，否则 整个叠加都贴不上（不只是标注，虚拟地形本身就错位）。
当前虚拟地形：水平 1:196,071 / 垂直 1:12,272 ⇒ 垂直夸张 16.0× （这个倍数与沙盘尺寸无关，改尺寸不会变）。
现场只需量一个数：实物沙盘上最高点高出基准面多少毫米 （基准面 = 模型最低的平坦面），填进「实物峰高」再点按钮即可。 虚拟峰高 = 直径的 5.1%（2.8 m 沙盘即 142 mm），可拿这个比例先目测核对。
⚠️ 前提是实物模型是同一套 DEM 的等比起伏。若是手工艺术化造型 （峰被压扁/丘陵被抬高），单一 reliefScale 只能整体逼近， 无法逐点吻合 —— 那种情况建议把标注放在基准面上，不要跟随虚拟起伏。

云台（台子）：pad 固定在台子上、底座不动，台子可绕竖直轴水平转、 绕水平轴上下转。两个轴的交点是唯一不动的点，所以相机位置只由 「交点到光心的偏移」决定：偏移 = 0 时转多少度位置都不动（纯旋转）， 偏移 ≠ 0 时相机沿圆弧平移，会让 AR 标注偏离真实地物。
把「光心偏交点」三个滑块调到 0 = 后摄光心正装在交点上的理想装法。 云台模式下会画出交点（黄点）、竖直轴（青）、水平轴（品红）和偏移杆（黄线）。
校准顺序：① 调「沙盘宽度」等于真实沙盘宽度 → ② 点底部「自动取景」让地形四角入画（用的是「取景俯角」，26° 接近人站着的视角） → ③ 再微调「相机高度 / 距离」匹配平板实际位置 → ④ 最后用「水平视场角」让虚拟地形边缘和真实沙盘边缘重合。
看顶栏「取景」徽章：显示「取景✓」表示四角都在画面内； 显示「上下超 1.3×」这类就说明某个方向出画了，点「自动取景」即可。
相机视场角无法从浏览器 API 拿到（getSettings() / getCapabilities() 都不提供），所以这里是手动滑块。
为什么近处看不全？平板后摄水平视场约 65°， 在 2 m 见方的沙盘前，物理上就装不下整个沙盘 —— 真实相机也拍不全， 所以虚拟地形超出画面其实是「和真实一致」的表现，不是 bug。
遮挡剔除：标签是「永远画在最上层」的（好处是不会被地形切掉半张）， 代价是锚点躲在山背后时标签仍浮在山脊上 —— 那会让「绑定在沙盘实体上」破功。 打开后每帧沿视线做高度场步进，锚点被地形挡住就一并隐藏标签。
视野裁剪关掉时遮挡也一并关（那是「一次性全渲染」对比模式， 两个机制同时变会看不出是谁在起作用）。
想单独看遮挡效果：视野裁剪保持开，只切这个开关。
